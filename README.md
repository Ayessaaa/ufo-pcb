## Features
- Has 3 LEDs that light up when the right button is pressed
- Vibration motor is triggered when the first button is pressed
- UFO art with Orpheus inside :D

## BOM
- 1 Battery holder
- 4 220 Resistor
- 2 Push Button
- 1 Mini motor disc
